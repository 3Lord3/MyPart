# Мой вклад в проект

## Мой вклад в идею

- Проработка пользовательских сценариев: от регистрации до завершённого обмена, подтверждения опасных действий, обратная связь на каждое действие;
- Этап отправки и получения товара: высылка товаров из ПВЗ только когда все участники принесут товары; фотографирование товара перед отправкой; получение после проверки товаров всеми участниками;
- Свободный выход из цепочки до начала её блокировки;
- Вместе с Даниилом Брагиным Danya-programmer механизм быстрой замены участника с предложением замены только получателю заменяемого товара;
- Краевые случаи: отказ/молчание участника при блокировке сделки, отсутствие быстрой замены.

## Мой вклад в реализацию

- **Интерфейс**: реализовал все экраны продукта - авторизацию, личный кабинет, управление товарами и запросами на обмен, цепочки обмена и их согласование, быструю замену выбывшего участника, сделки;
- **Макет**: спроектировал макет всех экранов, согласовывал дизайн и функционал с командой;
- **Логотип и название**: предложил идею логотипа и названия проекта, которые команда приняла. Реализовал логотип;
- **Визуал**: добавил переключение цветовой темы, плавные переходы;
- **Архитектура и качество**: выстроил архитектуру фронтенда (Feature-Sliced Design), покрыл важный функционал тестами, настроил линтеры и проверку типов.
